# ReConnection ᯤ

A pretty silly game but... ahem, here goes-

*ReConnection* is a short narrative game (visual novel) built with Ren'Py. You play as a newly introduced NPC who is guided through the hidden rules of a game world where NPCs are secretly conscious and must never let players notice. 🧿

When an unexpected outage disrupts the game, you and a cute little experienced NPC, Lemon Block, need to protect everyone, reach safety, and survive until the connection is restored.

## Story Premise

- You are a new NPC entering the game world for the first time.
- Lemon Block teaches you the most important rule: never reveal NPC consciousness to players.
- A sudden dark-system event traps NPCs outside their normal safe haven flow.
- The cast must gather in a lit area and wait for reconnection while avoiding suspicion.

## Gameplay

- Linear visual novel format.
- Character naming input at the start.
- Dialogue-driven pacing with scene transitions, music, and sound effects.
- One small branching menu choice for dialogue flavor.

## Main Characters

- Lemon Block: your guide and protector.
- [Player] notices: the meta-layer player presence in the story.
- You (custom name): a newly awakened NPC perspective character.

## Built With

- Engine: Ren'Py
- Language: Ren'Py script (`.rpy`)
- Assets: custom/background images, GUI resources, and audio files in the `game` folder

## Project Structure

- `game/script.rpy`: main story flow, dialogue, choices, and audio cues.
- `game/screens.rpy`: UI screens (dialogue, choices, quick menu, menus).
- `game/options.rpy`: game metadata and configuration (name, version, build settings).
- `game/gui.rpy`: GUI styling and layout configuration.
- `game/images/`: story/background and sprite assets.
- `game/audio/`: music and sound effects.

## Run Locally

1. Install Ren'Py from the official site.
2. Open the Ren'Py Launcher.
3. Add or select this project folder.
4. Launch the project to play.

## Build a Distribution

1. Open the project in Ren'Py Launcher.
2. Choose Build Distributions.
3. Select target platforms (for example macOS, Windows, Linux, Web).
4. Generate release packages.
